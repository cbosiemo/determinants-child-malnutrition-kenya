# Determinants of Child Malnutrition in Kenya

## Overview

This repository contains an end-to-end quantitative research project examining the determinants of child malnutrition among children under five years in Kenya using the 2022 Kenya Demographic and Health Survey (KDHS).

The project demonstrates a complete research workflow, including:

- Research design
- Data management and cleaning
- Survey-weighted statistical analysis
- Logistic regression modelling
- Interpretation of findings
- Reproducible research using Git and GitHub

## Research Question

What child, maternal, and household factors are associated with child malnutrition among children under five in Kenya?
